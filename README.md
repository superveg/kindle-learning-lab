# Kindle Learning Lab

Interactive learning activities for children aged 3–4, designed for Amazon Kindle E Ink readers.

## Project goals

Explore early math, literacy, shape recognition, branching stories, and simple games through large, high-contrast touch controls. Activities should emphasize learning and understanding, with a natural stopping point suitable for a suggested 10–15 minute session.

## Technical direction

- Static HTML, CSS, and Vanilla JavaScript.
- GitHub repository and GitHub Pages deployment; no dedicated backend.
- Kindle's built-in browser is the target; iPhone + ChatGPT is the primary development and discussion workflow.
- Black and white, large text, large buttons, and minimal screen updates.
- Prefer interactions that continue after the page has loaded if the connection briefly drops.
- Treat device-specific browser behavior and modern Web APIs as unverified until tested.

## Current status

This repository currently contains project documentation only. There is no runnable learning activity, and GitHub Pages deployment has not been verified.

The exact Kindle model, firmware, and browser capabilities are still to be supplied and tested.
