The SVG contents are unchanged. `tools/build_learning.py` rasterizes with Inkscape, crops empty margins and fits the artwork inside a 160×160 white PNG. Embedded PNG derivatives and object/location compositions containing these pictures are also distributed under CC BY-SA 4.0; other project materials retain their respective licenses. Attribution is accessible in the grown-up guide on every subject page and on `art-credits.html`.

Build dependencies: Python/Pillow and Inkscape. No browser-time vector renderer, network request or added JavaScript dependency is needed.

Inspect candidate pictures at their actual displayed size (including 48px composite inserts), in monochrome. A noun picture must depict the object clearly rather than rely on text or a generic symbol. Shoe and sock must have visibly different silhouettes. Changes to illustrations must preserve any visual feature used by a task clue; independent content checks and a rendered review remain necessary.
