## Checks

| Check | Expected result | Kindle result |
| --- | --- | --- |
| Initial load | Black text on white; four readable activity entries; no horizontal scrolling | Pending |
| Layout | Entry labels stay inside their borders; scrolling reaches the grown-up check | Pending |
| JavaScript | Screen check says "JavaScript is working." | Pending |
| Touch | Each of the three distinct touch targets updates once; final status is 3 of 3 | Pending |
| Text size | Larger text remains readable and reachable without horizontal scrolling | Pending |
| Count | Try a wrong answer, then the right one; Next stays unavailable until correct | Pending |
| Repeated taps | Tapping the correct number twice does not add score twice | Pending |
| Completion | Counting ends after three questions with a break message | Pending |
| Shapes | Square has straight sides; circle is visibly round; both can be tapped | Pending |
| Letters | A, B, and C display correctly; choosing A completes the sample | Pending |
| Story | Either choice produces one ending and disables both choices | Pending |
| Navigation | Every sample returns to the top of the Hub without reloading | Pending |
| Brief disconnection | Load online, turn off Wi-Fi, keep the page open, and try all samples | Pending |
| E Ink refresh | Text remains readable after several screen changes; note ghosting and response delay | Pending |

Offline reload/reopening is a separate capability and is not supported by this version. A failure after reopening does not invalidate the loaded-page disconnection check.

## Report issues

Record the activity, exact taps, expected result, actual result, and whether Wi-Fi was on. Add a photo if useful. Note whether an adult or child used the controls. Do not mark Kindle compatibility as confirmed until the relevant checks pass on a named device.
